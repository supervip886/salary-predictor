# 校招 Offer 薪资预测

综合学历层次、学校档次、专业背景、城市、行业、岗位、公司类型、实习经历、论文竞赛等多个维度，智能预测校招年薪区间。

## 线上地址

🌐 **[https://supervip886.github.io/salary-predictor/](https://supervip886.github.io/salary-predictor/)**

## 功能

- **8 步输入**：学历层次 → 学校与专业 → 目标城市 → 目标行业 → 目标岗位 → 目标公司 → 实习经历 → 加分项
- **智能薪资推演**：城市基准 × 学历学校 × 行业薪制 × 岗位加权（论文/竞赛/实习权重因岗位而异）× 公司系数
- **准入门槛校验**：不满足岗位最低要求（如大模型算法需顶会+ACM+大厂实习）会拦截提示
- **数据看板**：页面底部 📊 可查看本地统计

## 技术

纯前端单文件 HTML，零依赖部署，GitHub Pages 托管，Google Analytics 统计。
